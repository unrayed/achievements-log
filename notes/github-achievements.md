# GitHub Achievements — criteria and thresholds

Earnable as of 2026: Pull Shark (2/16/128/1024 merged PRs), Pair Extraordinaire
(1/10/24/48 coauthored merged PRs), Galaxy Brain (2/8/16/32 accepted Q&A
answers), Starstruck (16/128/512/4096 stars on one repo), Quickdraw (close
within 5 min), YOLO (merge with no review), Public Sponsor (active public
sponsorship), Finishing Touch (GitHub-classified UI PR).

Retired: Arctic Code Vault Contributor, Mars 2020 Contributor.
Disabled experiments: Heart On Your Sleeve, Open Sourcerer.

- Highest tier is shown on profile since 2026-09-11.
- Achievements are not exposed via REST or GraphQL.
- Coauthor credit needs a `Co-authored-by:` trailer in the merged commit.
- Squash merges can drop the coauthor trailer.
